# 实施与验证

## 当前实现

首版已实现中文 WPF 主窗口、托盘菜单、手动锁键、Ctrl+Alt+L 切换、三种 CatSit 键盘检测规则、1–10 档灵敏度、仅提示、持续锁定、松键后 1 秒自动恢复、可选提示音及当前用户开机启动。

Windows 钩子在独立消息线程运行。检测、屏蔽与按键配对均在该线程处理，界面通知异步发送；自动重复不计入检测，注入事件直接放行。滑动输入窗口最多保留 128 条事件。

物理按键与前台已经接收的按键分别跟踪：锁前已放行的按下事件允许其松开事件送达；被屏蔽的按下事件在解锁后仍消费其配对松开。人工解锁后等待旧按键全部释放，再开始新的检测序列。正常退出卸载钩子，输入处理异常和电源、会话切换会解除锁定并关闭自动防护。

## 与初始设计的差异

- 首版猫提示使用系统字体中的猫符号，尚未加入像素猫动画和外观选择。
- 托盘、设置和界面为本项目编写；复用的是上游检测代码及钩子结构，详见第三方声明。
- 自动防护关闭时保留钩子，用于识别全局手动锁定快捷键；退出时才卸载。
- 每次启动自动防护初始关闭；先由用户启用，避免未知环境中立即误锁。
- 快捷键固定为 Ctrl+Alt+L，后续可加入自定义和快捷键冲突提示。

## 已验证

2026 年 11 月 21 日，本地 Windows x64、.NET SDK 10.0.404：

- Release 编译通过，0 警告、0 错误。
- `tests/CatGuard.Checks` 的状态机可执行断言通过；具体断言见测试源码。
- 原生 EXE 三秒启动检查正常退出，记录 `HookInstalled=True; State=Off; UI=Loaded`。
- 在正常用户环境验证 AppData 设置文件成功保存。
- 从实际 WPF 窗口生成图像并检查文字、控件和设置区域；此项为程序自身渲染检查。

`--smoke-test` 仅在自动防护关闭状态检查启动，不会主动锁定用户键盘。可附 `--report <路径>` 保存简短状态，附 `--screenshot <路径>` 保存程序自身的窗口渲染。

## 仍需实机验证

状态机模拟与钩子安装检查尚不能证明真实物理键盘的屏蔽效果和恢复行为。物理键盘乱按、中文输入法、不同布局、管理员窗口、游戏输入、远程桌面、睡眠恢复与多键盘设备均应进一步实测；自动检测误报率尚未测量。

GitHub Actions 的运行结果以仓库实际记录为准，不包含在本地测试结论中。
