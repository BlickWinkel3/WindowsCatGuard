# 0.1.1 Windows 实机验收

日期：2026 年 11 月 21 日。测试在用户本机 Windows 上完成。

## 实体键盘

用户在专用接收窗口中实际操作键盘：同时按住 A、S、D、F，按 G，全部释放，恢复后按 H。验收程序采用与主程序相同的 `KeyboardHook.cs`、`GuardEngine` 和检测代码。

记录结果：

```text
PASS actual non-injected hardware events received
PASS actual hardware paw triggered and suppressed input
PASS G did not reach receiver during physical auto lock
PASS H reached receiver after physical auto release
State = Watching
Triggers = 2
Rule = PawCluster
PhysicalEvents = 106
InjectedEvents = 0
BlockedEvents = 95
Native failures: 0
```

这些记录确认：实体键盘事件经过 Windows 钩子后触发自动锁定；锁定期间接收窗口没有收到 G；松开并自动恢复后，接收窗口收到 H。最后一帧在 H 按下时结束，因此该帧的按住计数为 1，不代表恢复失败。测试结束时卸载钩子。

测试程序的 SendInput 标记分支没有参与此次实体键盘测试，因为模拟事件计数为 0。正式 EXE 不编译该测试标记分支。

## 其他验证

- 61 项核心回归断言通过。
- 本机原生输入链路的 8 项自动验收通过，涵盖未锁定时输入、手动锁定、人工恢复、混入 Ctrl 的自动触发、自动拦截及松键后恢复。
- 修复前，同一原生链路测试中手动锁定有效，自动触发失败；修复后通过。
- Release 编译及 win-x64 自包含发布通过。

## 结论范围

已验证本机普通桌面接收窗口中的自动检测、输入屏蔽和恢复。未验证所有输入法、键盘布局、游戏、管理员应用或远程桌面；这些环境仍需各自测试。
