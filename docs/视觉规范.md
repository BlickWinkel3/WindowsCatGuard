# WindowsCatGuard 0.2.0 视觉规范

参考用户提供的猫咪编辑器九宫格图，提炼其界面语言，不复制图中的标识和具体猫图。沿用此前指定的粉色与灰米色卡，并将参考图的明亮青蓝色用于主展示区。

| 项目 | 参考图观察 | 本项目规则 |
| --- | --- | --- |
| 字体 | 白色粗圆标题、较小的深色短标签、粗体选中项；画面没有细长大段正文 | Windows 优先使用 Microsoft YaHei UI；中文与英文标题 23–25 px、粗体；分组标题 12 px 粗体；正文 12–13 px；辅助文字 10–11 px。英文保持简短，不使用参考图的专有字标 |
| 排版 | 上部有高对比色的居中角色展示卡；下部用浅色设置面板与整齐的选项格 | 桌面版采用左侧 352 px 的猫咪舞台、右侧状态与设置两张卡；24 px 列间距；外边距约 29 px；状态、操作、统计、设置按使用顺序排列 |
| 组件 | 大圆角插画区、胶囊按钮、浅色选项块、选中描边、极简图标 | 主卡圆角 24–28 px；主按钮粉色胶囊、深色 2 px 描边；开关使用胶囊轨道与圆形滑块；统计是三张浅色块；灵敏度滑杆用粉色进度和圆点 |
| 颜色 | 青蓝、黄、绿等整块明亮背景，黑白高对比；白色区域承载操作 | 主舞台 `#56C4D4`，内衬 `#68D0DE`；前版色卡 `#FF94AB`（操作/选中）、`#FAF6F5`（纸面）、`#E2D7D5`（浅灰米）、`#CFC2BF`（猫斑/轨道）；文字和轮廓 `#332D31` |
| 描边与插画 | 猫是简化轮廓、平涂色块、粗黑线，细节点到为止 | 猫咪主体 3–3.5 px 深色描边，五官 2–2.5 px；白色身躯、灰米斑块、粉色鼻子；重叠的小耳与外耳构成简州猫的四耳轮廓意象；与键盘同用 WPF 矢量路径 |
| 动效 | 静态参考未规定动效 | 呼吸约 2.4 秒、尾巴往返约 1.75 秒、每 5 秒眨眼一次；鼠标靠近时头部最多转 6°；隐藏窗口或关闭动效时停止动画 |

参考图是手机端猫咪定制界面，功能与屏幕比例不同，因此桌面版保留其色块、粗描边和可爱简笔画风格，把复杂选项改成适合键盘防护的两栏信息层级。状态、解锁和快捷键始终在上方，文字对比度优先于纯粹复刻。
