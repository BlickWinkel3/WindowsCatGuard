# WindowsCatGuard 0.3.0 视觉规范

新参考图是三张学习应用手机界面。整体是**安静的浅色卡片系统**：留白多、信息层级明确、边框很轻，主要用浅紫、薄荷绿、奶油黄识别区域。下表将图中可观察的视觉语言转成当前 Windows 小窗口的规则。字号为视觉估计；桌面实际以 WPF 设备独立像素为单位。

| 要素 | 参考图分析 | 本项目落地 |
| --- | --- | --- |
| 字体 | 无衬线、圆润而紧凑；大标题明显加粗，辅助信息细而淡 | 中英使用 Microsoft YaHei UI 及系统回退字形；品牌 18 px Bold、状态 26 px Bold、区块标题 15 px Bold、正文 12–13 px、辅助字 10–11 px |
| 排版 | 纵向阅读顺序：顶栏 → 大标题/主内容卡 → 小统计卡 → 次要选项；每屏少量重点 | 单栏 510×690 px，最小 460×550 px；外边距 22 px，卡片间距 11 px，卡内边距约 19–20 px。状态和锁键按钮最靠上，统计居中，设置在下 |
| 组件 | 20 px 左右的大圆角卡、圆角 CTA、浅色分组块、右上角的小圆控件 | 主状态卡/设置卡圆角 23 px，统计卡 17 px，按钮 16 px，语言切换是双段小胶囊；自动防护置于薄荷绿块，其余选项保持轻量 |
| 颜色 | 近白底，浅紫主卡，薄荷绿与浅黄辅助卡；标题近黑，说明文字灰紫 | 背景 `#F8F7FC`、主卡 `#E8DFF3`、薄荷 `#DDF0EC`、奶油黄 `#FFF0BF`、强调紫 `#BDA7DE`、主字 `#242735`、次字 `#747888` |
| 描边与阴影 | 大部分组件没有粗黑线；靠微弱明暗变化区分层次，白卡边界柔和 | 移除上一版粗描边和大面积亮青蓝；卡片无可见描边，开关和滑杆用柔和的紫色状态；保留足够文字对比度 |
| 图标 | 小型单色线/面图标置于浅色圆角背景，不抢主内容 | 统一猫爪图标：浅紫底、深色爪印。用于 EXE、窗口标题栏、托盘和页头；图形源见 `assets/paw.svg`，Windows ICO 由 `tools/create-icon.ps1` 生成 |

这是一款桌面键盘防护工具，因此保留系统标题栏和清晰的解锁入口。参考图里的手机大插画不适合本次精简目标：窗口不再展示左侧猫咪，低频的锁定保持、声音、开机启动和诊断都折叠在“更多设置”中。
