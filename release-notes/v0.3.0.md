## English

WindowsCatGuard 0.3.0 introduces a compact, single-column interface inspired by soft pastel cards. The large cat illustration is gone; a paw icon now appears in the app, window and tray. Chinese and English remain switchable. Less-used options are grouped under **More settings**.

Download `WindowsCatGuard-v0.3.0-win-x64.zip`, extract the entire folder and run `WindowsCatGuard.exe`. Windows 10/11 x64; no separate .NET installation required. Automatic protection starts off each launch.

## 中文

WindowsCatGuard 0.3.0 改为精简的单栏小窗口，采用浅紫、薄荷绿与奶油黄的圆角卡片。移除了大幅猫咪插画，应用、窗口和托盘统一使用猫爪图标。继续支持中英切换，低频选项收进“更多设置”。

下载 `WindowsCatGuard-v0.3.0-win-x64.zip` 后解压整个文件夹，运行 `WindowsCatGuard.exe`。适用于 Windows 10/11 x64，无需另装 .NET。每次启动时自动防护默认关闭。
